* **Borders, Margins, and Paddings:** 
    These are the three different properties of each HTML element. Border specifies the border around the element. Margin specifies the space between the element's border and other elements. Padding is the inside area of the element, contained within the margin and the border.
* **HTML Classes:** 
    Can be styled in CSS by doing `.classname { some-property: some-value; }
