\## DISCOVERIES

\- Dictionaries store information as key-value pairs.

\- dictionary.keys() can get all keys from a dictionary.

\- sort(key=len) sorts strings by length.

\- random.shuffle() randomizes the order of a list.

\- % can be used to find leftovers when dividing into groups.
